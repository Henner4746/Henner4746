# Henrik

I build small, practical tools for Windows automation, self-hosting workflows, and local developer utilities.

## Focus Areas

| Area | Examples |
|---|---|
| Windows automation | PowerShell tooling, local installers, device/driver troubleshooting |
| Self-hosted utilities | Docker-based dashboards and lightweight admin tools |
| Local-first workflows | Exporters and scripts that avoid unnecessary cloud/API dependencies |
| Documentation | Clear setup guides, offline usage notes, and reproducible fixes |

## Principles

- Prefer local-first tools over unnecessary hosted services.
- Keep setup steps reproducible and documented.
- Make small utilities safe to inspect, run, and modify.
- Treat logs, prompts, paths, and exported developer context as sensitive data.

## Stack

PowerShell, Python, Flask, Docker, Windows internals, SQLite, GitHub tooling.
